Data Compiler

Combine any number of CSV/Excel files into one table, merging copies of the same data.

1. Import files

Accepts .csv, .xlsx, and .xls files (the first sheet of each workbook is used). Add as many as you need.

    2. Choose how to spot copies

    Rows that have the same values in every checked column are treated as copies of the same record and merged into one row (ignoring case and extra spaces). Check every column to only merge exact copies. The default is a guess — adjust it if needed.

    3. Review compiled data

    merged from several copies copies disagreed (first value kept — hover to see all) column added by a later file

    4. Export

    Downloads a formatted .xlsx workbook with a "Compiled Data" sheet, plus "Duplicates", "Conflicts", and "Columns" sheets explaining what was merged and where each column came from.

    Runs entirely in your browser — files are never uploaded anywhere.
